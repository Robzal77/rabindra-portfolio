# Rabindra Rizal — Portfolio

A compact, evidence-led portfolio for Rabindra Rizal: data, analytics, automation and responsible AI program leadership.

Built with Astro and deployed as a static GitHub Pages site. Content is intentionally kept in one page component so it remains easy to review and update.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

Pushes to `main` deploy automatically through `.github/workflows/deploy.yml` after GitHub Pages is configured to use **GitHub Actions** as its source.
