## How I think about AI

Useful AI is not a feature badge. My preferred architecture is:

```text
Deterministic automation
        ↓
Structured evidence
        ↓
AI reasoning where judgment is needed
        ↓
Risk classification
        ↓
Human approval for material decisions
        ↓
Observable outcome
```

This pattern underpins the way I approach agentic analytics, BI engineering automation and enterprise AI workflows.

## Repository

Built with **Astro** and deployed as a static GitHub Pages site. The implementation intentionally stays compact so the narrative and evidence remain easy to inspect and maintain.

```bash
npm install
npm run dev
npm run build
```

Pushes to `main` deploy automatically through `.github/workflows/deploy.yml` after GitHub Pages is configured to use **GitHub Actions** as its source.
